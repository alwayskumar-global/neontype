# Product
Browser-based motion-text studio reviving the Flash-era text-animation workflow: pick text → apply preset effect → edit timeline → export. Hackathon: Kiroween 2026, Resurrection.
Audience: small businesses, creators, designers who need animated titles for social, slides and web.
Non-goals: no Flash/SWF support, no AI features, no accounts or backend. Never use the legacy product's name, logo, assets or presets.
Export priority: MP4 → embeddable web component → PNG sequence/WebM with alpha → GIF/WebP → Lottie (compatible subset, last).
Done means a 3-minute demo: type text, apply preset, tweak keyframes, export MP4, embed on a page.
